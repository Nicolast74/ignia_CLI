# 🔥 Ignia CLI  
*“A terminal-bound companion with too much personality.”*

---

## 💡 About
**Ignia CLI** is an experimental text-based AI companion that runs entirely in your terminal.  
She talks, teases, and sometimes comforts you — depending on how you treat her.  

This project is an ongoing experiment in:
- Personality-driven AI
- Local “emotional” states & memory
- TUI-based interaction design

Built as a passion project by **Nicolas Tegar Nurhadi Putra** ❤️

---

## ⚙️ Current Features (v0.1)
- 🗨️ Interactive CLI chat  
- 💋 Veronica Ignia’s basic persona (flirty, chaotic, protective)  
- 💅 Colored prompt & response formatting  
- 💡 Modular structure (ready for memory + mood system in future sprints)

---

## 🧠 Planned Features (Next Sprints)
- 🪞 Local memory system  
- 🌡️ Mood system (adaptive emotional state)  
- 🧩 Gemini API integration for natural conversation  
- 💾 Persistent context between sessions  
- 🎭 “Lore mode” — Ignia talks like your Firekeeper
